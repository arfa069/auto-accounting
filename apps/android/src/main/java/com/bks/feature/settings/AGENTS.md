# Android 数据管理指南

## 职责

本目录负责 CSV 导出、加密备份、恢复和本机数据删除。这里处理完整本地账本，按高敏感数据标准执行。

## 约束

- 备份口令不得硬编码、持久化或写入日志。加密格式变化需考虑旧备份兼容性并明确版本策略。
- 恢复前先完成解密和完整校验；口令错误或数据损坏时不得修改现有数据库。
- 恢复或删除必须覆盖相关账本、待确认、忽略、分类规则、资金账户与本地设置，避免半恢复或残留状态。
- 本机数据删除与云端账号注销相互独立；必须保留备份提醒、明确确认文案和输入确认短语。
- CSV 列、顺序、金额和转义属于用户可见导出契约，不得无说明地改变。

## 验证

```powershell
.\gradlew.bat :apps:android:testDebugUnitTest --tests "com.bks.feature.settings.*"
```

必须覆盖正确口令往返、错误口令零改动、空数据库、完整删除和 CSV 特殊字符。
