# Android 账本与报表指南

## 职责

本目录将已确认的 Room 账本记录映射为界面模型，并提供账本查询、月度汇总、分类排行和趋势计算。

## 约束

- Room 中的已确认记录是账本真相；Screen、示例数据和临时 Compose 状态不得覆盖持久化结果。
- 金额使用最小货币单位整数；收入、支出和净额符号必须一致，格式化只发生在展示边界。
- 月份与日期计算必须使用明确时区。分类排行只统计约定范围内的支出，趋势保持固定排序和空月份语义。
- 报表函数只派生结果，不修改输入记录；搜索和筛选不得改变底层账本。
- Entity 到 `LedgerUiEntry` 的映射变化必须同步检查报表聚合和界面。
- 点击账目行直接进入共享编辑表单；删除入口位于编辑页并继续走 30 天最近删除与撤销链路。
- 账目新增和编辑只选择已有资金账户；新资金账户统一从独立资金账户管理页创建。

## 验证

```powershell
.\gradlew.bat :apps:android:testDebugUnitTest --tests "com.bks.feature.ledger.*"
```

覆盖空账本、跨月、收入与支出、分类汇总、六个月趋势和映射字段。
