# Android 账单同步指南

## 职责

本目录负责用户主动账单同步、微信/支付宝支付结果与账单页解析、去重及待确认队列交接。

## 约束

- 不能把 Manifest 声明当作已授权。未授权时只引导系统设置，不启动来源应用或伪造同步进度。
- 无障碍 Service 只在用户主动发起的手动补录会话中处理当前可见支付应用账单页；不采集输入框、聊天内容、付款发起或无关页面。
- 微信手动补录在 Android 11 及以上可对当前可见的账单页使用本机瞬时截图 OCR；OCR 必须命中完整支付/退款签名并包含唯一金额，任一拒绝词出现即不处理。图片始终不得保存或上传；OCR 原文默认不落库、不上传，唯一日志例外是用户主动开启的本机敏感诊断日志，且必须加密并先脱敏认证秘密。
- 解析结果必须经过去重和分类建议后进入待确认队列，绝不直接生成账本记录。
- Session 阶段、进度、成功、失败和取消必须保持一致；失败不得悄悄改变队列。

## 验证

```powershell
.\gradlew.bat :apps:android:testDebugUnitTest --tests "com.autoaccounting.feature.billsync.*"
```

覆盖无权限、空页面、解析失败、重复候选、Session 失败及正常完成。
