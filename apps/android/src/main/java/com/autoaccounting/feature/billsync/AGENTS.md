# Android 账单同步指南

## 职责

本目录负责用户主动账单同步、自动记账无障碍事件、微信/支付宝支付结果与账单页解析、去重及待确认队列交接。

## 约束

- 自动记账必须经过独立开关且无障碍权限健康，但不得要求用户先完成手动账单同步或开启通知监听。
- 不能把 Manifest 声明当作已授权。未授权时只引导系统设置，不启动来源应用或伪造同步进度。
- 无障碍 Service 仅处理允许的支付应用、支付结果和支付记录页面；不采集输入框、聊天内容、付款发起或无关页面。
- 微信页面没有可读节点时，仅在自动记账开启，或用户从待确认页选择来源并启动当前手动补录会话，且 Android 11 及以上使用本机瞬时截图 OCR。来源选择自动授予仅本次会话有效的 OCR 权限。自动路径保持窄 Activity 白名单；手动路径可识别当前可见的微信历史账单详情且不限定 Activity，但必须同时满足“当前状态:支付成功”和唯一金额，任一拒绝词出现即不处理。图片始终不得保存或上传；OCR 原文默认不落库、不上传，唯一日志例外是用户主动开启的本机敏感诊断日志，且只允许支付页或当前补录会话、必须加密并先脱敏认证秘密。
- 解析结果必须经过去重和分类建议后进入待确认队列，绝不直接生成账本记录。
- Session 阶段、进度、成功、失败和取消必须保持一致；失败不得悄悄改变队列。

## 验证

```powershell
.\gradlew.bat :apps:android:testDebugUnitTest --tests "com.autoaccounting.feature.billsync.*"
```

覆盖无权限、空页面、解析失败、重复候选、Session 失败及正常完成。
