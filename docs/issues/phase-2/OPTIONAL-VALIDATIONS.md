# 可选真机验证清单

本文件记录不属于当前默认验收范围、需要产品负责人明确决定后才执行的真机验证。未获确认的项目不得主动操作、采集或扩大无障碍读取范围。

## 待决定

### 支付结果页小组件

- **状态**：仅作产品参考，当前不实现。
- **参考体验**：支付完成后在屏幕下方展示由应用维护的小组件，显示识别金额、收入或支出等信息，等待用户编辑并确认入库。
- **实现边界**：该方案可能涉及悬浮显示、后台展示和敏感交易信息暴露；当前版本不新增桌面小组件、悬浮窗权限，也不扩大现有通知或无障碍采集范围。
- **如需验证**：先明确组件形态、展示时机、锁屏行为、最小字段、用户关闭方式和隐私告知，再由产品负责人单独授权原型或真机验证。

### 应用锁定至后台教程

- **状态**：仅作产品参考，当前不实现。
- **参考体验**：通过品牌相关视频或图文，指导用户在最近任务界面将应用锁定，降低被系统清理的概率。
- **实现边界**：Android 没有标准授权入口或可靠状态检测；不得把用户是否完成锁定显示为可验证的系统权限状态。
- **如需验证**：按手机品牌和系统版本维护教程，并确认入口变化、无障碍影响和退出指引后再单独实施。

### 微信钱包账单中的红包记录/交易详情

- **状态**：暂不验证，等待产品负责人决定。
- **目的**：确认微信发送红包没有独立成功页时，钱包账单、红包记录或交易详情是否提供可读无障碍节点，能否作为延迟补录来源。
- **隐私影响**：页面可能同时暴露其他账单、交易对象、历史金额和账户信息，读取范围明显大于单次支付结果页。
- **当前默认**：不进入 Issue 16 的自动记账主流程，不要求用户打开该页面，不进行真机节点检查，也不据此放宽无障碍页面白名单。
- **如需验证**：必须先明确最小读取范围、脱敏证据格式、停止条件和数据不留存要求，再由产品负责人单独授权。
