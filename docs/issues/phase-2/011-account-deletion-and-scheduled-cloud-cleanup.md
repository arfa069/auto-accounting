# Issue 011: 持久化账号注销与定时云端清理

## 待构建内容

实现账号注销的端到端持久化：申请注销、进入注销等待状态、暂停云端写入、允许在冷静期内取消，以及执行定时清理云端账号数据。

## 验收标准

- [x] 账号注销申请连同冷静期截止时间及注销等待状态一并持久化。
- [x] 用户可以在冷静期内登录并取消注销。
- [x] 注销挂起期间暂停云端 AI 及设备/配置写入。
- [x] 定时清理任务彻底删除账号、已注册设备、云端配置及 AI 分类日志。
- [x] 测试覆盖申请、取消、写入阻断、定时执行及幂等删除行为。
