# 合规与隐私评估草案 (Compliance And Privacy Draft)

本文档属于产品与工程合规评估草案，不构成法律意见。在公开发布到应用商店前，法务团队应对隐私政策、用户协议、权限说明文书、第三方服务清单、AI 日志策略及账号注销流程进行全面复核。

参考依据锚点：
- [《中华人民共和国个人信息保护法》官方数据库](https://flk.npc.gov.cn/detail2.html?ZmY4MDgxODE3YjY0NzJhMzAxN2I2NTZjYzIwNDAwNDQ%3D=)
- [Google Play 无障碍服务 API 政策](https://support.google.com/googleplay/android-developer/answer/10964491)（即使目标为国内 Android 商店，仍作为风险参考标准）。

## 1. 商店合规材料包 (Compliance Package)

内测发布前必须准备齐全以下材料：
- 隐私政策。
- 个人信息收集清单。
- 第三方服务清单。
- 权限使用说明页面。
- 针对自动记账无障碍服务的应用商店审核说明材料。
- 展示权限使用说明及通用识别边界的界面截图或录屏。

## 2. 数据分类 (Data Classification)

敏感交易信息定义：
- 交易金额。
- 商家/标题。
- 账单文本。
- 分类。
- 交易类型。
- 资金账户。
- 支付来源。
- 交易时间。
- 备注说明。

由于上述信息能够揭示用户的财务状况、生活习惯及活动规律，均被严格视为**敏感个人信息**。

## 3. 个人信息收集清单 (Personal Information Collection List)

建议罗列项：

- **用户名、邮箱与手机号码**：用户选择的主标识及后续主动绑定的登录标识，用于注册、登录、找回密码与身份校验；用户名注册不收集验证码，邮箱和手机号分别通过 SMTP 邮件与短信验证。本地模式不收集这些标识。
- **微信身份与资料**：用户主动使用微信登录、注册、绑定或合并时，后端处理 OpenID、可用时的 UnionID、昵称和 HTTPS 头像 URL；用于识别唯一微信身份和展示资料。每次成功授权刷新，解绑微信或账号注销完成后删除；Android Session 不保存 OpenID、UnionID 或微信 Token。
- **公开账号 UUID 与账号 Profile**：后端为每个账号生成不可变 UUID，用于账户管理页展示、复制和人工识别，不作为认证凭据。用户主动设置的昵称和头像保存在账号 Profile 中；Android 仅上传压缩后的头像数据，不上传相册中的其他图片。
- **密码哈希值**：用于密码登录验证；账号模式下为必需。
- **设备信息**：用于已注册设备安全防护、防欺诈、验证码限流及配置分发；账号模式与验证码风控所必需。
  - Android 端为此目的使用随机生成的应用安装 UUID，不读取任何硬件标识符。
  - 安装 UUID 在设备端保留至本机数据删除或卸载；后端注册设备记录在账号注销完成后删除。
- **其他应用当前活动窗口的可见文字**：仅在用户开启自动记账且无障碍服务运行时，于设备内短暂解析已完成交易；只采集可见、非密码、非输入框文字，不截图、不操作其他应用。原始页面文字、未命中内容和无关页面信息不保存、不写入诊断日志、不上传。
- **账本与待确认条目数据**：用于本地记账功能；核心记账业务所必需。
- **AI 分类 Payload**：用于提供云端 AI 分类建议；属于可选功能。
- **增强 AI 上下文**：用于提高云端 AI 分类的准确率；属于可选功能。
- **AI 分类日志**：用于内测期间改进服务质量；通过 AI 同意获得可选授权，在公开发布前必须重新评估留存策略。
- **内测就绪与质量指标**：仅在 Debug 开发者工具中展示的本地衍生就绪状态与聚合 QA 输入；不构成独立的原始日志存储。
- **敏感诊断日志**：当前包含用于排查应用故障的完整异常栈；自动记账页面文字与交易字段不得写入。Debug 默认开启；Release 默认关闭并要求独立的知情同意。
- **应用分发统计数据**：用于应用商店分发与基础分发效果测量。

重要分类原则：
- 本地交易处理是记账的核心必需项。
- 云端 AI 分类属于完全可选的附加功能。

## 4. 权限使用边界 (Permission Boundaries)

自动记账无障碍服务 (Automatic Bookkeeping Accessibility Service)：
- 目的：仅在用户主动开启自动记账后，读取第三方应用当前活动窗口中可见、非密码、非输入框文字，识别明确完成的交易并创建待确认项。
- 隐私政策必须明确声明：应用不截图、不执行 OCR、不发送消息、不点击或滚动其他应用、不发起支付、转账或退款。
- 原始页面文字只在内存中短暂解析；无论接受或拒绝，都不进入 Room、诊断日志、备份、账户同步或任何上传链路。

敏感诊断日志 (Sensitive Diagnostic Logging)：
- 绑定设计与运维控制详见 [ADR 0063](./adr/0063-replace-platform-capture-with-assists-generic-recognition.md) 与 [DIAGNOSTIC-LOGS.md](./DIAGNOSTIC-LOGS.md)。
- 在 Debug 和 Release 构建中均可用。Debug 默认开启；Release 默认关闭并要求在“合规与隐私”下进行显式确认。
- 当前生产事件可记录应用异常；自动记账页面文字、解析交易字段、拒绝内容和无关页面信息不得记录。
- 绝不存储截图。身份凭证与密钥（如密码、验证码、Token、Cookie、Authorization 报头、API 密钥、备份口令、签名密钥、微信 code/票据）以及 OpenID、UnionID 在写入前始终脱敏；账号流程不记录昵称、头像 URL 或 Provider 正文。
- 事件使用 Android Keystore AES-256-GCM 在 `noBackupFilesDir` 中独立加密；1 MB 分段仅在密文总大小超过 10 MB 时滚动删除。日志不上传，也不包含在账本/系统备份中。
- 关闭开关停止记录新事件但不删除历史。清除操作会删除所有分段及 Keystore 密钥。本地数据删除还会删除 Release 偏好设置，而已导出到 Downloads 的文件仍由用户自行管理。
- 导出需要至少 8 个字符的非持久化口令及确认，并生成独立加密的 `.aadiag` 文件。

云端 AI (Cloud AI)：
- 默认处于关闭状态。
- 需要用户明确授权同意。
- 默认仅传输最小化字段。
- 增强上下文需要用户单独勾选授权。
- AI 日志仅在内测期间保留，公开发布前必须重新界定。

账户账本同步：
- 默认关闭，首次启用前明确告知正式账本字段会以服务端可读取形式保存，并列出不上传的设备采集证据与设置。
- 生产仅使用 HTTPS，并要求受控数据库权限与存储层静态加密；局域网 HTTP 只用于显式开启的受控测试环境并持续显示风险。
- 不上传待确认、已忽略、自动记账原始页面文字、诊断日志、备份文件、权限设置、自动记账开关或当前账本选择。

## 5. 第三方服务清单 (Third-Party Service List)

首版引入的第三方服务类别：
- 腾讯微信开放平台与微信 OpenSDK：仅用于用户主动发起的微信授权登录、注册和账号绑定；Android 通过 OpenSDK 发起授权，后端使用 code 换票并获取 OpenID、可用时的 UnionID、昵称和 HTTPS 头像 URL。不向微信发送账本、交易、备份或诊断日志，AppSecret 与微信 Token 不进入 APK。
- Coil / OkHttp 开源组件：Coil 用于显示 HTTPS 微信头像或设备端已解码的账号 Profile 头像，OkHttp 仅参与 HTTPS 远程头像获取；组件本身不提供遥测或云端存储。图片使用独立、上限 10 MB 的本机缓存，并在头像更新、退出、解绑、Session 失效或本机数据删除时清理。
- Assists 开源无障碍组件：仅引入 `assists-base`，在应用进程内提供 Android 无障碍 Service、Listener 和活动窗口节点读取；不使用 `assists-mp`、`assists-opcv`、截图、OCR 或自动操作能力，不向 Assists 服务上传页面或交易数据。
- 短信服务商。
- SMTP 邮件服务商：仅接收目标邮箱、一次性验证码、用途说明与 5 分钟期限；不接收密码、Token、账本、交易、备份或诊断日志。
- 云端 AI 提供商。
- 无诊断日志服务商：敏感诊断日志保留在设备端，该功能绝不上传日志。
- 应用分发统计服务商。

首版明确排除：
- 广告 SDK。
- 营销追踪 SDK。

第三方清单中各项应包含：
- 提供商名称。
- 服务目的。
- 收集个人信息类别。
- 处理方式。
- 数据留存或删除策略（若有）。
- 提供商隐私条款链接。

## 6. 数据留存策略 (Data Retention)

按数据类型明确写明留存期限：

- **本地账本**：在设备端持续保留，直至用户删除条目、删除本机数据、卸载应用或恢复/替换数据。
- **云端同步账本**：仅在用户启用同步后随账号保留；删除墓碑与增量用于防止离线旧设备复活数据，账号最终注销时与 Profile、冲突和幂等记录一并删除。本机账本不随云端注销删除。
- **待确认条目**：保留至被确认、忽略、删除或被产品规则过期处理。
- **已忽略条目**：可恢复期限为 30 天。
- **加密备份**：导出后由用户自行控制。
- **CSV 导出文件**：导出后由用户自行控制，应明确说明为纯文本格式。
- **账号数据**：账号存在期间持续保留；在账号注销冷静期满后予以删除。
- **公开账号 UUID 与账号 Profile**：随账号持续保留；账号最终注销时删除。设备端头像缓存会在头像变化、退出、解绑、Session 失效或本机数据删除时清理。
- **微信身份与 Provider 资料**：绑定期间保存并在每次成功授权后刷新；解绑微信或账号注销完成后删除。用户后续设置的账号 Profile 不因解绑微信而自动删除。
- **已注册设备与云端配置**：账号存在期间持续保留；账号注销完成后予以删除。
- **AI 分类日志**：内测期间保留；在应用商店公开发布前必须重新复核留存期限。
- **内测就绪与质量指标**：仅作为普通本地应用状态或显式 QA 记录保留；不创建独立的原始日志存储。
- **短信与邮件验证数据**：仅按验证、防欺诈、审计与安全所需的最短期限保留；服务端只保存带用途和标识类型隔离的验证码 HMAC，不保存验证码明文。

## 7. 用户权利与控制选项 (User Rights And Controls)

应用内提供的控制项：
- 查看隐私政策与个人信息收集清单。
- 查看第三方服务清单。
- 开启/关闭云端 AI。
- 开启/关闭增强 AI 上下文。
- 在技术可行时清除 AI 分类日志。
- 导出 CSV。
- 导出/导入加密备份。
- 查看并复制公开账号 UUID，修改账号昵称和头像，补绑或换绑手机号/邮箱。
- 申请注销账号。
- 在 7 天冷静期内取消账号注销。
- 通过单独的确认流程删除本机数据。
- 开启或关闭自动记账，并在需要时打开系统设置管理无障碍授权；权限或服务断开不会悄悄改变开关意图。

## 8. 账号注销与本机数据删除 (Account Deletion And Local Data Deletion)

账号注销流程：
- 触发 7 天冷静期。
- 冷静期内，用户仍可登录并取消注销。
- 冷静期内，暂停云端 AI 及设备配置的写入。
- 冷静期满后，清理云端账号、已注册设备、云端配置及 AI 分类日志。
- 先清理 AI 日志和云端配置；若任一清理失败，保留等待注销账号以便稍后重试，避免部分删除账号身份。

账号凭据与 Session 处理：
- Android 端使用 Android Keystore AES-GCM 加密业务 Token、公开账号 UUID、主标识、登录标识列表、微信绑定状态、注销状态、昵称和头像值，并保持在账本备份、诊断及日志之外；OpenID、UnionID、AppSecret、SMTP/短信凭据和微信 Token 不进入客户端 Session。
- 后端仅将验证码作为服务端密钥 HMAC 值存储，Session Token 仅作为 SHA-256 哈希值存储。安全迁移将使旧的临时凭据作废，而不是保持明文兼容。
- 验证码 IP 限流使用服务端观察到的远程地址；客户端提交的 IP 值将被忽略。

本机数据删除流程：
- 独立于账号注销的设置入口。
- 优先展示备份提醒。
- 要求输入确认文本：“删除本机数据”。
- 从设备上清除本地账本及应用数据。
- 删除诊断分段、其 Keystore 密钥及 Release 开启偏好设置。警告已导出到 Downloads 的 `.aadiag` 文件不会被自动删除。

## 9. 应用商店审核风险点 (Store Review Risks)

高风险关注区域：
- 无障碍服务。
- 云端 AI 数据上传。
- AI 分类日志留存。
- 账号注销与数据删除。
- 敏感界面上的猫咪陪伴文案。

缓解与规避措施：
- 使用清晰透明的权限申请文案。
- 提供结构化的隐私与合规材料。
- 自动记账默认关闭，只读取活动窗口的可见、非密码、非输入框文字，并以 512 节点、24 层、16 KiB 为硬上限。完成态、唯一金额、明确方向和交易上下文缺一不可；原始页面文字不持久化、不记录、不上传。
- 使诊断日志入口在两个构建版本中均可见，默认对敏感值脱敏，后台/退出时重新脱敏，在透出时应用 `FLAG_SECURE`，并要求加密口令导出。
- 页面清晰区分用户开关意图、无障碍授权和服务连接状态。
- 默认采用本地规则，保持云端 AI 默认关闭。
- 绝不引入任何广告或营销追踪 SDK。
- 即使有猫咪陪伴角色，敏感界面仍保持严肃、清晰、无歧义的表述。
