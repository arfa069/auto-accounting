# ADR 0060: 统一账号标识并区分代码能力与真实 Provider 就绪状态

账号密码认证统一使用用户名、邮箱或手机号作为登录标识，并全部归属不可变的内部 `accountId`。每个账号共享一份密码凭据、失败次数和锁定状态；用户名注册不需要验证码，邮箱和手机号注册、找回及绑定分别要求对应渠道的验证码。找回密码只接受已绑定并验证的邮箱或手机号，不提供短信验证码直接登录，纯用户名账号未绑定联系方式时不能自助找回。

微信身份继续作为同一 `accountId` 下的可选登录方式。Android 仅在配置公开 AppID 时展示微信入口，后端仅在 AppID/AppSecret 完整配置时处理真实 OAuth；缺少任一配置时必须安全隐藏或返回稳定的未配置错误，不影响密码登录和本地模式。真实短信、SMTP 和微信是否可用，以对应 Provider 配置与真实端到端验收为准，不能用假 Provider 自动化或代码完成状态替代。

密码账号之间的标识冲突不得自动合并、转移或覆盖凭据；微信纯账号与密码账号的互补合并仍遵循 [ADR 0057](./0057-use-internal-account-id-for-wechat-identity.md) 的单事务、票据和 Session 轮换边界。本决定取代 [ADR 0017](./0017-use-phone-password-login-with-sms-recovery.md) 中“仅手机号作为密码登录标识”的现行约束，并保留其密码加固与验证码找回原则。
