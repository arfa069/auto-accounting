# ADR 0059: 增加账户级账本同步并保持 Room 离线优先

已登录用户需要在多台设备间共享正式账本数据，同时应用仍必须在离线、后端不可用或 Session 未验证时允许本地记账。此前 [ADR 0005](./0005-store-ledger-locally-while-reserving-cloud-sync.md) 与 [ADR 0018](./0018-keep-first-backend-out-of-ledger-data.md) 将“不在首版后端存储账本”作为阶段性边界；该边界现已不能满足多端同步需求。

Room 继续作为 Android 的离线数据源，后端按不可变 `accountId` 隔离并保存该账户的同步 Profile、当前记录、增量、幂等结果和冲突。同步范围仅包括账本、正式及最近删除账目、分类、资金账户和分类规则；待确认、已忽略、采集证据、设备权限/监控设置、诊断日志、备份文件和当前账本选择保持设备级。账目同步 Payload 明确排除 `evidenceSummary`、`parsedFieldsText` 与 `originPendingEntryId`。

客户端把本地业务写入与 outbox 写入放在同一 Room 事务，按“推送持久化 outbox、拉取增量、事务应用远端数据”执行。服务端使用记录版本和递增游标；过期 `baseVersion` 生成可人工处理的候选冲突，不静默覆盖。分类和资金账户按业务唯一键采用云端规范 ID 并重映射本机引用；同名但不同 ID 的账本均保留，本机账本确定性增加“（本机）”后缀。

首次启用前必须告知同步范围、服务端可读存储、传输要求及注销影响，确认后才上传。同步默认仅接受 HTTPS；只有本地忽略配置显式开启时，HTTP 才可连接回环或 RFC1918 地址，且界面持续显示测试风险。这收紧了 [ADR 0058](./0058-allow-explicit-http-backends-for-android-builds.md) 对账本同步流量的边界，但不改变既有账号测试端点配置。

注销冷静期允许读取并暂停写入，最终注销删除全部云端同步数据，本机账本保留并解除账号绑定。签出只暂停同步；重新登录同一 Profile 恢复。切换账号前必须清空原账号 outbox，并在单个 Room 事务中用目标账号正式数据替换同步范围，绝不把上一账号数据自动上传给新账号。

因此，本 ADR 仅替代 ADR 0005/0018 中“后端不存储或同步账本”的现行约束；旧 ADR 继续作为历史记录。本地优先、待确认先审核、设备级采集证据及独立加密备份等决策保持有效。
