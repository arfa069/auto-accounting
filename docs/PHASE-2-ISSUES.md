## Issue 2: 持久化待确认队列与已忽略条目

### 待构建内容

### 验收标准
- [ ] 从应用捕获路径创建的待确认条目在 Activity 重建和进程重启后在待确认队列中依然可见。
- [ ] 确认、忽略、撤销及已忽略条目恢复通过仓储/持久化层运行，而非仅保存在 Compose 状态中。
- [ ] 已忽略条目保留恢复元数据，且不作为账本条目出现。
- [ ] 待确认队列的分组、置信度状态、捕获原因、疑似重复状态及证据展示在重启后依然保留。
- [ ] 仓储与 UI/集成测试覆盖“待确认 -> 已忽略”与“已忽略 -> 待确认恢复”流程。
